# Noumena Atelier — portfolio

単一 HTML 完結のポートフォリオ。`index.html` をダブルクリックで開く。サーバ不要・オフライン動作・外部リクエストゼロ。

## ヒーローの結晶

WebGL2 + 生 GLSL（ライブラリ不使用）。両端終端の六方晶クォーツを **解析的な凸多面体交差**で描画している。

- 18 半空間平面（柱面 6 + 上錐面 6 + 下錐面 6）。r 面 / z 面の交互サイズなど実際の水晶の非対称性を再現
- 凸形状なのでスラブ法の 1 パスで**入射点と射出点が同時に求まる**。レイマーチングを完全に排除
- 光路: 屈折して内部へ → 内部を進行 → 屈折して射出（全反射時は最大 3 回バウンス）→ 環境をサンプル
- R/G/B を別々にトレースして**分散（fire）** を出し、Beer–Lambert 吸収で厚い部分だけ淡いアクア色に沈む
- 柱面には水晶特有の**横条線（striation）**

後処理は 4 パス: シーン → ブルーム水平 → ブルーム垂直 → 合成（エッジ検出 AA + アナモルフィック光条 + ACES トーンマップ + グレイン）。

### 軽さの担保
- 解析交差により、1 ピクセルあたりの評価が SDF 数千回相当 → 平面テスト約 126 回に低減
- **適応解像度**: フレーム時間を計測し 0.34〜1.30 倍の範囲で自動調整（遅い端末は自動的に軽く、速い端末は自動的に精細に）
- サムネイルは**一度だけ描画**し、以後はホバー中のみ再描画
- 画面外・タブ非表示時は描画停止
- WebGL2 非対応時は Canvas2D にフォールバック

## 調整箇所

| 目的 | 場所 |
|---|---|
| 結晶の形状・透明度 | `SCENE_SRC` 冒頭の定数（`PR` `PDT` `PDB` `IOR` `DISP` `ABSORB`） |
| ライティング | `KEY_D` / `RIM_D` / `FIL_D` と対応する `*_C` 色 |
| 描画負荷の上限 | `var Q={scale, min, max}` |
| 配色 | `:root` の `--ice` / `--violet` / `--ink*` |
| 書体 | `:root` の `--serif` / `--sans` / `--mono`（すべてシステムフォント。CDN 非依存のため Google Fonts は使わない） |
